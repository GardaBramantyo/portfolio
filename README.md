# Garda · AI-powered studio: sample projects

Sample deliverables for four services. All brands, people and numbers are fictional, and every sample was tested before it went up.

**Live site:** open `index.html`, or visit the Cloudflare Pages link in the repo description.

| Folder | Service | What's inside |
|---|---|---|
| [`gig1-data/`](gig1-data/) | Excel, CSV and PDF data cleaning | Before and after files for a customer list cleanup, a PDF statement and invoice reconciliation, and a two-file sales merge |
| [`gig2-landing/`](gig2-landing/) | Coded landing pages (HTML + Tailwind CSS) | Three live demos: SaaS, skincare and coffee subscription |
| [`gig3-n8n/`](gig3-n8n/) | n8n AI automation workflows | Importable workflows with error handling, mock test scenarios and results |
| [`gig4-python/`](gig4-python/) | Python automation and scraping | Three runnable projects with config, logging, offline tests and real run output |

No API keys, passwords or real personal data are in this repo. Credentials in the samples are placeholders or read from environment variables.
